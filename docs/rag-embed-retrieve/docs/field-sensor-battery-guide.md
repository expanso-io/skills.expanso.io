# Field Sensor Battery Guide (synthetic)

Remote soil and weather sensors run on a single lithium thionyl chloride primary cell. These cells hold a flat voltage for most of their life and then fall off sharply, so the remaining-capacity estimate is based on voltage under load, not at rest.

Replace the battery when the loaded voltage reported in the sensor heartbeat falls below 3.3 volts. Below 3.1 volts the radio can brown out mid-transmission and corrupt the last reading.

Spent cells are not household waste. Tape the terminals, bag each cell individually, and return them to the depot for certified recycling.

Never recharge a primary lithium cell. Doing so can vent the cell and start a fire inside the enclosure.
