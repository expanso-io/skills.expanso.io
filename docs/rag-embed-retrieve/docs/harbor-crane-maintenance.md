# Harbor Crane Maintenance Standard (synthetic)

Ship-to-shore cranes at Berth 7 run two shifts a day, so maintenance is scheduled around the tide table rather than the calendar. Every crane carries a logbook in the operator cab, and each entry must name the technician and the hour-meter reading.

Wire ropes on the main hoist must be visually inspected every 250 operating hours and fully measured for diameter loss every 1,000 hours. A rope is retired when it shows six or more broken wires in one lay length or a diameter reduction above 7 percent.

Slewing ring bolts are torque-checked quarterly. Technicians mark each bolt head with a paint stripe after torquing so a loose bolt shows as a broken line during the daily walkaround.

Lubrication of the trolley wheels uses a lithium-complex grease applied weekly. Over-greasing attracts grit from the bulk cargo terminal next door, so apply no more than two strokes of the grease gun per fitting.
